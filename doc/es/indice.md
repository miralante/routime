## 📂 Estructura de `doc/`

```
doc/
├── es/                     ← Documentación en español
│   ├── indice.md           ← Este archivo (mapa de la documentación)
│   ├── roles.md            ← Roles del proyecto y por dónde empezar
│   ├── SPEC.md             ← QUÉ es Routime, PARA QUIÉN y POR QUÉ
│   ├── guia-rapida.md      ← Cómo abrir la app (4 métodos) y cómo usarla
│   ├── guia-crear-elementos.md ← Cómo crear actividades nuevas
│   ├── actividades.md      ← Catálogo completo de las 68 actividades
│   ├── equipo.md           ← Guía para familias y profesionales de apoyo
│   ├── tecnico.md          ← Arquitectura, APIs y recetas de desarrollo
│   ├── contenidos.md       ← Tabla de contenidos
│   └── i18n.md             ← Sistema multiidioma
└── en/                     ← English documentation
    ├── index.md            ← Documentation map (this file's mirror)
    ├── roles.md            ← Project roles and where to start
    ├── SPEC.md             ← WHAT Routime is, WHO it's for, and WHY
    ├── quick-guide.md      ← How to open the app (4 methods) and use it
    ├── creating-elements-guide.md ← How to create new activities
    ├── activities.md       ← Full catalog of all 68 activities
    ├── team.md             ← Guide for families and support professionals
    ├── technical.md        ← Architecture, APIs and development recipes
    ├── contents.md         ← Table of contents
    └── i18n.md             ← Multilingual system
```

El resto de documentos del repositorio (`CLAUDE.md`, `LICENSE`,
`README.md`, `CONTRIBUTING.es.md`, etc.) viven en la **raíz**.
