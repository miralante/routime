# Guide for professionals and families

This guide is intended for occupational therapists, families and professionals who want to use Apptonomia as a support tool.

---

## Who is Apptonomia for?

Apptonomia is primarily designed for:

- **People with intellectual disability** who want to practice daily living skills
- **Families** looking for resources to work on at home
- **Occupational therapists** who need complementary tools for direct intervention

The application **does not replace** professional intervention, but can serve as:

- Reinforcement between sessions
- Autonomous practice at home
- Progress tracking of the user

---

## How to use Apptonomia in therapy

### Initial assessment

Before using the application, observe the user with these questions:

1. What level of autonomy do they have in daily life?
2. What skills do they want to work on? (autonomy, memory, motor skills, etc.)
3. What activities are attractive or motivating to them?
4. Do they need support to use technological devices?

### Activity selection

#### For users starting out

| Activity | Skill worked |
|----------|--------------|
| **Pairs** | Visual memory, attention |
| **Catch It** | Eye-hand coordination |
| **Coloring** | Fine motor skills |
| **Traces** | Movement precision |
| **How do I feel?** | Emotional recognition |
| **My Routines** | Temporal sequencing |

#### For intermediate users

| Activity | Skill worked |
|----------|--------------|
| **Spot the Difference** | Attention to detail |
| **The House** | Household task sequencing |
| **My Schedule** | Time planning and anticipation |
| **Safe Chat** | Internet safety |

#### For advanced users

| Activity | Skill worked |
|----------|--------------|
| **Dominoes** | Strategy, counting |
| **The Shop** | Money use, calculation |
| **Emergencies** | Crisis decision-making |
| **The Theatre** | Spatiality, complex instructions |
| **Among Friends** | Social skills |
| **Visual Sudoku** | Logical reasoning |

### Adaptations

#### Difficulty level

Each activity has **3 levels** (Easy → Medium → Hard). To choose:

- **Level 1 (Easy)**: New users or those with significant support
- **Level 2 (Medium)**: Users with moderate experience
- **Level 3 (Hard)**: Autonomous users looking for challenge

#### Reductions

If Level 1 is still too difficult, you can:

- Reduce the number of elements (e.g., fewer cards in Pairs)
- Provide physical support to guide movement
- Use the activity as demonstration before requesting autonomy

## Progress tracking

### Stars

Each activity saves **stars** when completed:

- ⭐ = 1 star (level completed)
- ⭐⭐ = 2 stars (several levels)
- ⭐⭐⭐ = 3 stars (all levels)

To view progress:

1. Access settings by typing `/ajustes` at the end of the URL
2. Check "My progress" for a summary

### Manual log

For more detailed tracking, you can use this template:

```
Date: _______________
User: _______________
Activity: _______________
Level used: _______________
Observations:
___________________________________
___________________________________
Supports needed:
___________________________________
```

## Usage recommendations

### Frequency

| Goal | Recommended frequency |
|------|----------------------|
| Maintenance | 2-3 times per week |
| Skill improvement | Daily or almost daily |
| Introduction of new activities | 3-4 times per week |

### Duration

- **Short sessions**: 10-15 minutes for new users
- **Medium sessions**: 20-30 minutes for intermediate users
- **Long sessions**: 30-45 minutes for advanced users

### Guidelines for families

If you are a family member working with Apptonomia at home:

1. **Don't constantly correct**: let the user explore and fail without pressure
2. **Celebrate attempts**: not just correct answers
3. **Follow their interest**: if an activity motivates them, use it more
4. **Respect the pace**: don't force if the user is tired or frustrated
5. **Communicate with the therapist**: share what works and what doesn't

## Safety and privacy

### Data

- **No personal data is collected**: the application doesn't require registration
- **Progress is saved locally**: only on the device used
- **No internet connection needed**: works offline

### Sensitive content

Some activities deal with sensitive topics:

| Activity | Topic | Recommendation |
|----------|-------|---------------|
| **Emergencies** | 112, dangerous situations | Review first, accompany if necessary |
| **Important Phone Numbers** | 112, dangerous situations | Review first, accompany if necessary |
| **My Details** | The person's and family's real address and phone numbers | Needs to be set up beforehand in `/settings/` (address and phone numbers); without that the activity only shows a notice |
| **Safe Chat** | Online manipulation | Requires support from a support person |
| **Bullying Chat** | Peer bullying | Always with professional supervision |
| **Should I Post It?** | Social media | Requires support from a support person |
| **Social media, intimacy and law** | Sexual manipulation, digital intimacy and legal consequences | Always with professional or family supervision |
| **My Body, My Choices** | Consent, relationships, contraception, hygiene and sexual health, pressure and blackmail, protection and infections | Always with professional or family supervision |
| **I Tell the Doctor** | Putting a body symptom into words for a health professional | Review first; pairs well with **My Body Tells Me** |
| **My First-Aid Kit** | Everyday self-care at home, knowing when to ask for help or call 112 | Review first; level 2 explicitly trains asking a trusted person or 112 |
| **Circle of Trust** | In-person manipulation in friendships and requests for money | Requires support from a support person |

## Solving common problems

### The user gets frustrated

1. Switch to an easier activity
2. Lower the difficulty level
3. Use the "Back" button to exit
4. Come back another day

### The activity is too easy

1. Move to the next level
2. Introduce a new activity
3. Let them decide when to repeat or switch activities

### Audio doesn't work in an activity that should have it

Remember: only some activities use audio (gamification or design
needs, e.g. hearing what is typed on the keyboard or listening to a
sequence). If a 🔊 button is missing from an activity, that is
expected — audio is not applied by default.

When the 🔊 button is present and audio doesn't work:

1. Check the device volume
2. Check browser permissions
3. Try a different browser (Chrome or Firefox)
